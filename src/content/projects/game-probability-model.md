以數學建模為核心，設計一套 RTP = 95%、高波動性（σ ≈ 7.77）的老虎機遊戲數學模型。

從賠付表設計、Variance 推導、Hit Frequency 計算出發，並以 Python 對 10,000 位玩家進行蒙地卡羅模擬，驗證理論 RTP 與模擬結果誤差小於 0.01%。

產出五張視覺化圖表，涵蓋玩家體驗曲線、公司 P&L、RTP 收斂分析，完整呈現遊戲數學設計與風控邏輯。
