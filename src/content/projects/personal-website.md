## 解決什麼問題

需要一個可以長期維護、方便更新的線上作品集，讓企業快速了解我的背景與作品。

## 技術重點

- 以 Astro Content Collections 管理專案，欄位有型別檢查
- 響應式設計，手機與桌機皆可良好瀏覽
- 自動跟隨系統深色 / 淺色模式
- 推送到 GitHub 後由 GitHub Actions 自動建置部署
